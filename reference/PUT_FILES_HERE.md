# Drop files here for the report

Upload two things into this folder:

1. **Suganth's report** (`Suganth_-_HCD_report_updated.pdf`)
   Used purely as a formatting sample: font name, font colour, font sizes,
   heading styles, margins, and the Table of Contents / List of Figures layout.

2. **Implementation screenshots** (PNG or JPG)
   One image per screen. If the file names say what the screen is
   (e.g. `home.png`, `admin-dashboard.png`) that helps, but it is not required.

Then say **"uploaded"** in the chat and the report will be rebuilt.

Nothing in this folder changes the running application.
